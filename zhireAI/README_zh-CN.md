# 挚热AI渲染器 V2

面向 Cinema 4D 的场景驱动 AI 效果图插件。它把当前活动视图、参考图、图文提示词和输出参数整理成一个可配置请求，并把生成结果带回 C4D 面板进行预览、对比和历史管理。

当前版本：`V2.0.7`。

## 当前版本包含

- 独立 C4D 场景槽：橙色第一槽可点击上传图片或视频，也可接收“渲染加载”的结果，并和后面的普通参考图保持间距与颜色区分。场景图始终作为请求中的第一张自动参考，不需要输入 `@`，也不占用普通参考图编号。右键场景缩略图可将完整原图复制到系统剪贴板。
- 最多 8 张普通参考图：只有在提示词中通过 `@` 插入 `[[图N]]` 后，该图才会进入当前 AI 请求；未被点名的参考图不会自动发送。单击缩略图可在 C4D 图片查看器中查看，右键可复制完整原图，右上角 `×` 可单独删除。几何捕获生成的 Z 深度缩略图也支持右键复制原图。
- 图像/动画双模式：右上角使用抗锯齿的深浅灰分段切换按钮，不再额外使用蓝色。自绘控件始终把点击交给插件真实窗口；后台完成通知延迟或丢失时也会自动解除忙碌状态，因此“渲染图像 / 渲染动画”和“渲染加载”不会无故失效。挚热 API 会按账号返回的模型记录图像能力；没有可调用的动画模型时，图像功能照常使用，动画段会弹出明确说明。
- 场景媒体双入口：点击空的“场景/动画”缩略图可以直接上传图片或视频；也可以点击下方“渲染加载”。两种来源都会保存同一份主动画标记、原始宽高与画幅。Atlas 优先上传符合要求的完整 MP4；旧版生成或手动上传的视频若像素、帧率或 50MB 大小不符合 Seedance 限制，会自动改用从同一动画提取并校正的有序参考帧，不再显示平台原始 400 错误。APIMART 会在 C4D 内把同一 MP4 自动解析成 5–12 张按时间排序的轻量参考帧，既保留首尾与中间运动，又降低 Seedance 2.5 在 50% 预处理阶段的负担。动画加载使用当前工程的正式渲染器、灯光和材质，以 C4D“完全渲染”逻辑输出约 1024px 长边且满足最小总像素的 MP4；所有支持的横竖画幅都会动态计算偶数尺寸，而不是使用可能低于平台门槛的固定小尺寸。编码不可用时回退的动画帧也会经过相同校验。点击 MP4 动画缩略图后由 C4D 原生 `MovieLoader` 解码，在 C4D 内置播放窗口中播放、暂停或逐帧查看。
- 渲染加载进度：C4D 文档渲染使用主线程安全调用原生渲染器，避免后台线程修改活动文档导致跨版本不稳定；原生渲染回调会显示实时进度。渲染完成后直接写入场景/动画槽，不自动弹出查看器。
- 图文提示词：空输入框显示“请在这里输入提示词”占位状态，鼠标点入后立即消失，不会进入生成请求；默认 1 行，右上角“行数”与数字步进器之间保留清晰间距，可在 1–13 行之间调整高度。编辑区域使用比面板略浅的稳定灰色底和细边界，让宽高范围始终可见。插件直接读取编辑框自身的稳定宽度，并在长文字影响 C4D 布局之前先为中英文插入仅用于显示的硬换行；键盘输入期间不会把内容造成的面板扩张误认为用户拖宽。提交和历史保存时会自动移除显示标记，每次重排后恢复原光标位置，方向键、选区和中间插入仍按系统习惯工作。键入 `@` 即可选择参考图并插入 `[[图1]]`、`[[图2]]`。
- API 快速连接：设置页仅保留挚热 API（JuAIHub）。右侧显示 API Key、API 地址、生成 Endpoint 和模型；“连接并使用”会读取当前账号可用的图像模型。Banana 2 使用实时可用的 `gemini-3.1-flash-image-preview`，旧版 `nano-banana-*` 别名不会再发送到接口。
- 专业 API 参数：连接平台时会保存平台返回的模型列表；动画前端只显示与当前平台 V2 参考动画契约相符、且该 Key 实际可见的 Seedance 模型，不能仅靠名称中出现 `seedance` 就误开启。图片与 Seedance 动画各自的 Endpoint、模型、请求模板及同步/异步响应路径统一收进折叠区。
- 后台生成：网络请求在 C4D 后台工作线程中运行，界面保持可操作，并显示状态和进度。动画请求提交前会统一检查参考素材的画幅、边长、总像素、帧率与文件大小；挚热 API 按账号可用模型执行对应的图像或动画请求。轮询遇到 `The read operation timed out`、短暂断网或 408/5xx 时会自动恢复并继续查询原任务；素材上传与结果下载可安全重试 3 次。只有“生成请求已发出但没收到响应”时不会自动重提，会用中文提醒先查看平台任务记录，避免重复扣费。
- 三阶段进度：保留清晰的蓝色“立即生成”主按钮，按钮内显示准备素材、AI 生成、保存结果、百分比与已用时间；生成时不会再次截取视图或覆盖已确认的构图。
- 顶部效果预览：效果图占满面板可用宽度；白模 MP4 和 AI 动画会显示首帧及播放入口，单击预览区即在 C4D 内播放。白模与 AI 动画同时存在时，“对比”会打开同一时钟驱动的左右双画面播放器；图片对比仍使用中央滑动手柄。右上角 `×` 只关闭当前预览，不删除历史、参考图或本地文件。
- 输出设置：自动模式从第一张场景图读取精确宽高；当服务商不接受 960×540 等小画布时，请求阶段会保持比例临时放大到合法尺寸，下载后再恢复并验证为 C4D 场景的精确像素，避免服务端直接拒绝或缺省回落成 1:1。也可手动选择 1:1、5:4、4:5、4:3、3:4、3:2、2:3、16:10、10:16、16:9、9:16、2:1、1:2、21:9、9:21；1K/2K/4K；1–4 张。
- 历史管理：每条记录都保存为完整工作现场，包含图像/动画模式、结果、提示词、主场景或白模动画、普通参考图、模型、画幅与输出参数。单击任意图像或动画记录会同步回填顶部效果窗口、提示词窗口和下方全部素材槽；不存在素材的记录也会清空上一条残留内容。双击只打开 C4D 图片/动画查看器，不重建主界面、不改变当前面板滚动位置；右键记录可选择“打开文件位置”，由资源管理器直接选中本地图片或动画。点击后的记录只使用中性灰行底和细分隔提示选中状态。历史区一次显示 8 条记录，超过 8 条可把鼠标放在列表上滚轮浏览。
- 自定义保存路径：历史面板底部的“设置保存路径”可选择任意有写入权限的文件夹；之后生成的效果图会自动保存到该位置。该路径独立于 API 平台，切换服务商不会覆盖；未设置时继续使用插件默认的 `renders` 文件夹。
- 跨版本稳定按钮：“渲染加载 / 上传参考 / 粘贴”和 API 平台选择使用插件自绘圆角表面，不依赖各版本 C4D 的原生边框着色。API 平台默认整块灰色、唯一连接成功的平台整块蓝色、连接失败整块红色。
- 历史查看：双击历史记录的缩略图、文字区或整行空白位置，都可打开原始结果；图片使用 C4D 图片查看器，动画使用 C4D 内播放窗口，查看时主面板保持固定。右键任意记录可打开文件位置并选中对应文件。
- 紧凑纵向工作流：默认宽度约 340px；“对比 / 刷新 / 设置”保持同排，并使用 8px 间距划分各自点击区域。
- 参数直接合并在参考图下方，不再显示独立“模型与输出”模块；生成完成后，顶部效果图与历史会同步更新。
- 参考图快捷上传：点击“＋上传参考”或任意空白缩略图，都可以选择参考图。
- 剪贴板参考图：Windows 与 macOS 均可直接点击“粘贴”读取剪贴板图片；同时保留添加、缩略图单独删除和图文标记。
- 场景摘要：可把文档名、当前帧、对象/材质数量、选择对象和相机信息作为 `$SCENE_CONTEXT` 发送。
- C4D 几何锁定：开启“锁定视图构图与模型形体”后，挚热 API 请求会在最终提交前强制把场景图恢复为第一视觉输入。构图提示在用户描述前后各设一道硬约束，锁定摄像机、画布、主体包围框、中心、尺寸和边距；Banana 2 使用参考图自动比例。画布宽高可做到确定性一致；主体语义位置仍受远程生成模型影响，锁定通过第一视觉输入与双重约束尽量降低偏移，不宣称对任何第三方模型都能像素级复制内容。

## V2.0.7 平台能力

下表描述的是本版内置适配器能力，不代表用户账号一定拥有对应模型权限。“连接并使用”会验证连接，并在平台提供模型列表时读取当前 Key 可用模型；没有兼容图像编辑模型时不会误设为已连接。如果图像模型可用但没有可调用的 Seedance 模型，图像生成仍可使用，动画入口会禁用并用中文弹窗说明原因。

| API 平台 | AI 图像 | Seedance 动画 | 当前内置能力边界 |
| --- | --- | --- | --- |
| 挚热 API（JuAIHub） | 支持 | 按账号模型 | Banana 2 使用 `gemini-3.1-flash-image-preview`；同时支持 `gemini-3-pro-image-preview`、`gpt-image-2`、`gpt-image-2.5-flare` 与 `gpt-image-2.5-sunburst`。 |

上述内置协议已通过离线请求/响应契约测试。实际调用仍受平台接口更新、账号权限、额度和网络影响；本项目不会把“未使用用户真实 Key 进行付费请求”写成已完成线上实测。

## 安装

当前统一 Python 3 构建的正式兼容目标为 Cinema 4D R23、S24、R25、S26、2023、2024、2025 和 2026，支持 Windows 与 macOS。R23 自带 Python 3.7，本插件以 Python 3.7 作为最低语法基线；已在 Windows 的 Cinema 4D 2023 中完成原生加载与渲染验证，其他目标版本完成静态兼容和接口回退检查。未来尚未发布或尚未验收的 C4D 版本不能预先承诺永久兼容，发布前仍建议在对应版本做一次实际启动测试。

R22 及更早版本使用 Python 2.7，无法与现代 Python 3 插件共用同一个代码包；如需支持这些历史版本，应另行维护 `Legacy Python 2.7` 构建，而不能把一个包标注为真正的“全历史版本通用”。

1. 在 Cinema 4D 中打开“编辑 → 设置”，点击“打开设置文件夹”。
2. 在该目录中建立 `plugins` 文件夹（如果还没有）。
3. 把完整的 `zhireAI` 文件夹复制到 `plugins` 中，确保入口文件是：

   ```text
   plugins/zhireAI/lumastage_ai.pyp
   ```

4. 重启 Cinema 4D，在“扩展”菜单中打开“挚热AI渲染器 V2”。面板可以自由停靠。

开发版使用临时插件 ID `1069587`。正式发布或销售前，必须在 Maxon Plugin Café 申请唯一 ID，并修改 `lumastage/constants.py` 中的 `PLUGIN_ID`。

## 第一次使用

1. 点击顶部“设置”。
2. 选择“挚热 API（JuAIHub）”，粘贴自己的 API Key；地址默认是 `https://api.juaihub.cn`。
3. 若只想记录当前平台参数，点击“保存设置”；它不会连接，也不会改变正在使用的平台。需要启用时点击“连接并使用”，插件会验证当前平台的 API Key、地址与 Endpoint，读取模型，并把它设为唯一使用的平台。
4. 只有当服务商协议与默认模板不同时，才展开“专业参数”，按其文档调整 Endpoint、Headers、请求模板和结果路径。
5. 选择“渲染图像”或“渲染动画”。点击空的主缩略图可上传图片/视频；点击“渲染加载”则按当前 C4D 渲染设置输出场景图。动画模式下若格式为 MP4 会直接输出并加载整段 MP4，否则加载有序动画帧。
6. 直接输入场景提示词即可；只有需要普通参考图时才输入 `@` 选择后方图槽。
7. 图像模式选择画幅、精度和数量；动画模式选择平台读取到的 Seedance 全能参考模型、画幅、时长和 480P/720P/1080P/4K 分辨率，然后点击“立即生成”。普通提示词自动作用于主动画，只有被 `@` 点名的普通参考图才会随任务提交。

插件会从挚热 API 的 `/v1/models` 读取账号当前可用模型。Banana 2 和 Banana Pro 按 DUMIK v0.1.6 的 Gemini 原生格式调用 `/v1beta/models/{model}:generateContent`，场景图、深度图和参考图按顺序作为 `inlineData` 发送；GPT Image 2/2.5 使用 OpenAI 兼容 Images API。Banana 2 对应 `gemini-3.1-flash-image-preview`，旧版 `nano-banana-*` 名称仅作为旧会话的兼容迁移，不会再发送到接口。

建议把密钥放在操作系统环境变量中，并在“Key 环境变量”填写变量名；这样插件设置文件中不需要保存明文 Key。

## 停靠与响应式布局

- 始终采用单列纵向信息流，宽度变化只让内容横向舒展，不会自动展开第二或第三栏。
- 顶部预览工具使用“品牌标题 + 对比 / 刷新 / 设置”单行结构，三个工具之间保留独立间距；各主模块之间使用稳定留白和分隔线。
- 参考模块顶部是深浅灰图像/动画模式切换，下一行是独立场景槽加普通参考槽，再下一行是等高的“渲染加载 / 上传参考 / 粘贴”。底部“立即生成 / 取消”填满完整宽度。
- “自动”画幅会根据已确认的手动渲染图宽高比选择最接近的输出比例；没有场景图时回退到 1:1。

如果旧的 C4D 工作区记住了以前的宽停靠尺寸，只需拖动一次停靠分隔线到约 340px；新版单列布局不会再占用大面积透视视图。

## API 模板变量

| 变量 | 类型 | 含义 |
| --- | --- | --- |
| `$MODEL` | string | 设置中的模型名 |
| `$PROMPT` | string | 去除 `[[图N]]` 标记后的纯文本 |
| `$RAW_PROMPT` | string | 保留图片标记的原始提示词 |
| `$NEGATIVE_PROMPT` | string | 反向提示词 |
| `$WIDTH` / `$HEIGHT` | integer | 计算后的像素尺寸 |
| `$SIZE` | string | 如 `2048x1152` |
| `$SIZE_STAR` | string | 如 `2048*1152` |
| `$COUNT` | integer | 生成数量 |
| `$SCENE_IMAGE_DATA_URL` | string | 场景图 Data URL |
| `$SCENE_IMAGE_BASE64` | string | 不带前缀的场景图 Base64 |
| `$REFERENCE_IMAGES_DATA_URLS` | array | 仅提示词中被 `@` 点名的普通参考图 Data URL |
| `$REFERENCE_IMAGES_BASE64` | array | 仅被点名的普通参考图 Base64 |
| `$SCENE_IMAGE_URL` | string | 上传后可供远程模型访问的场景图 URL |
| `$REFERENCE_IMAGE_URLS` | array | 上传后的参考图 URL |
| `$ALL_INPUT_IMAGE_URLS` | array | 场景图与参考图的远程 URL 合集 |
| `$MULTIMODAL_CONTENT` | array | 按图文顺序生成的内容数组 |
| `$DASHSCOPE_CONTENT` | array | 阿里百炼图像编辑的图像/文字内容数组（最多取前 3 张输入图） |
| `$SCENE_CONTEXT` | object | C4D 场景与相机摘要 |
| `$ASPECT` / `$QUALITY` | string | 画幅比例与精度，例如 `16:9`、`2K` |
| `$VIDEO_MODEL` | string | 动画模式独立模型名 |
| `$ANIMATION_FRAMES_DATA_URLS` | array | C4D 白模动画帧 Data URL，按时间排序 |
| `$ANIMATION_FRAME_URLS` | array | 上传后的白模动画帧 URL，按时间排序 |
| `$ANIMATION_REFERENCE_IMAGE_URLS` | array | Seedance 的主动画帧/主图片与被 `@` 点名的普通参考图 |
| `$ANIMATION_REFERENCE_VIDEO_URLS` | array | Seedance 的主 MP4/MOV 动画，自动作为第一视频参考 |
| `$DURATION` | integer | 动画时长（秒） |
| `$VIDEO_RESOLUTION` | string | 动画分辨率：`480p`、`720p`、`1080p` 或 `4k` |
| `$VIDEO_RATIO` | string | 自动画幅时为 `adaptive`，手动画幅时为所选比例 |
| `$SCENE_MEDIA_DATA_URL` / `$SCENE_MEDIA_URL` | string | 上传或渲染加载的主图片/视频媒体 |
| `$ALL_INPUT_MEDIA_URLS` | array | 主动画及被 `@` 点名的普通参考图，按全能参考顺序排列 |

当模板中的整个值恰好等于某个变量时，数组、数字和对象会保持原类型；变量嵌入普通字符串时会转换成文本。

### 同步响应示例

如果服务返回：

```json
{
  "data": [
    { "url": "https://example.com/result-1.png" },
    { "url": "https://example.com/result-2.png" }
  ]
}
```

把“结果 URL 路径”设置为 `data.*.url`。如果返回 `b64_json`，则把 Base64 路径设置为 `data.*.b64_json`。

### 异步任务

启用“提交后轮询”后，需要配置：

- 任务 ID 路径，例如 `task.id`；
- 轮询 Endpoint，例如 `/api/tasks/$TASK_ID`；
- 状态路径，例如 `task.status`；
- 最终 URL 或 Base64 路径。

可从 `presets/custom-async.json` 开始修改。

## 数据位置与隐私

插件不会在渲染加载或添加参考图时自动上传文件；只有点击生成后，场景槽和被 `@` 点名的普通参考图才会按当前模板发送到你配置的 API。

设置、捕获图、结果和历史默认保存在 Cinema 4D 的 Preferences 目录下：

```text
zhireAI/
  settings.json
  history.json
  captures/
  renders/
```

“清空历史”只清理历史索引，不删除磁盘上的生成图片，以降低误删风险。

Windows 上 C4D 2023 的典型默认结果目录为：

```text
C:\Users\<用户名>\AppData\Roaming\Maxon\Maxon Cinema 4D 2023_<安装标识>\prefs\zhireAI\renders
```

用户也可以在历史记录上点击右键，选择“打开文件位置”，无需手动查找这个目录。

设置自定义保存路径后，新生成的效果图会改存到所选文件夹；`history.json` 仍保留在 `zhireAI` 数据目录，用来索引这些图片。路径记录在 `output.json` 中，不与任何 API Key 或平台配置混合。

## 版权与安装包保护

- `LICENSE_zh-CN.txt` 明确规定正常用户的安装与使用权，禁止未经授权的换名打包、转售、公开分发和以仿制销售为目的拆解。
- `copyright.json` 保留产品 ID、品牌名称、官方渠道和隐私声明，`integrity.json` 记录关键发行文件的 SHA-256 特征。
- 插件启动时仅在本地检查官方安装包的归属信息和关键文件；发现缺失或篡改时显示一次警告，不会删除文件或损害用户工程。
- 这项校验不采集、不上传 API Key、提示词、图片、C4D 场景或设备标识，也不使用破坏性防调试行为。

Python 插件无法在终端用户设备上做到绝对不可逆向。本方案的目标是留下明确权属证据、识别盗改安装包并提高非法二次分发成本，同时不牺牲正常用户的跨版本兼容性和数据安全。

## SDK 限制

Maxon 的 Python API 没有开放 `BaseDraw.GetViewportImage`，因此无法直接复制实时视口帧缓冲。插件采用 Maxon 官方建议的 Hardware Preview Renderer 路径，并临时复制活动编辑器相机；它会保留相机构图，但某些第三方 IPR、视口叠加层或厂商专用后处理不会出现在捕获图中。

## 跨版本与跨系统设计

- 插件仅使用 Python 标准库和 Cinema 4D Python API，不依赖 Windows DLL、第三方二进制扩展或固定盘符。
- 设置、历史、捕获图与结果目录都从 Cinema 4D Preferences 路径取得，Windows 与 macOS 使用同一套数据结构。
- 主工作流使用 C4D 文档渲染器生成构图图，不依赖 Windows 屏幕截图；“渲染加载”不会自动打开图片查看器，查看器仅在用户点击参考图或历史缩略图时使用。旧的实时视口像素捕获只作为 Windows 辅助回退，不参与正式生图流程。
- 自绘界面使用显式窗口绑定，并对 R25 才加入的 `GeUserArea.GetDialog()` 等宿主差异采用能力检测与旧版回退；全部 Python 文件保持 R23 的 Python 3.7 语法可解析。
- 系统级功能分别适配 Windows PowerShell、macOS AppleScript，以及系统默认的文件夹打开方式。
- 正式公开分发前必须将开发用插件 ID 替换为 Maxon Plugin Café 分配的唯一 ID；否则与其他插件发生 ID 冲突时，任何系统和版本都无法保证稳定加载。

## 开发验证

在项目根目录执行：

```powershell
python -m unittest discover -s tests -v
```

`tools/validate_c4d_api.py` 可使用 Cinema 4D 自带的 `c4dpy` 检查插件依赖的 SDK 符号；某些机器需要先完成 Maxon App 授权。

`tools/validate_render_pipeline.py` 会在 C4D 运行时创建临时场景，验证文档渲染、128×96 输出尺寸、MovieLoader、动画时间范围以及位图/对象/渲染设置的 `GetClone` 路径。两个验证脚本都会清理已加载的 `lumastage*` 模块，并确认实际导入位置属于 `ZHIREAI_PLUGIN_ROOT`，防止把系统中另一份已安装插件误当成当前源码验收。
