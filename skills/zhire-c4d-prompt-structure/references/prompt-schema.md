# 提示词结构参考

## 推荐骨架

```text
任务定义：在第一张 C4D 场景母图的原画布上完成产品视觉渲染，只改变被允许的材质、环境与灯光。

构图锁定：保持原摄像机位置、朝向、透视、焦距、主体数量、主体包围框、画面占比、遮挡关系和四周留白；保持原始宽高关系；禁止裁切、扩图、缩放、平移或旋转主体。

产品结构：准确保持产品外轮廓、部件数量、连接方式、厚薄关系、开孔、把手、五金、Logo 位置和所有可识别设计特征。

材质与色彩：写明允许改变的表面材质、粗糙度、反射、纹理尺度和颜色；没有获得授权的部分保持场景母图。

场景与灯光：写明环境类型、接触面、背景、主辅光方向、软硬程度、阴影、反射控制、曝光和景深。

参考图职责：[[图1]] 只参考……；[[图2]] 只参考……。不得继承参考图中的产品结构、镜头或品牌。

质量要求：边缘干净，接触阴影可信，材质尺度真实，产品清晰，无悬浮、穿插或变形。

禁止项：不得新增或删除产品部件；不得改变镜头和构图；不得把内部 Z 深度图的灰度解释为颜色、材质、光照或背景。
```

## 图槽规则

| 输入 | 提示词写法 | 职责 |
| --- | --- | --- |
| C4D 场景母图 | 不写编号 | 摄像机、画幅、构图、产品形体与空间关系的最高优先级依据 |
| 内部 Z 深度图 | 不写编号 | 近白远黑的几何、轮廓、遮挡和空间层次约束 |
| 普通参考槽 1 | `[[图1]]` | 仅承担提示词明确指定的视觉职责 |
| 普通参考槽 2 | `[[图2]]` | 仅承担提示词明确指定的视觉职责 |

未写入 `[[图N]]` 的普通参考槽不会进入当前请求。不要把“请求图像序列中的第几张”与插件界面中的 `[[图N]]` 混用。

## Banana2 示例

```text
在第一张 C4D 场景母图的原画布上完成高端电商产品渲染。严格保持原摄像机、透视、产品位置、锅体与手柄比例、锅盖和灶架遮挡关系、主体画面占比及四周留白，保持场景母图原始宽高关系，不裁切、不扩图、不缩放、不平移、不旋转、不重塑产品。产品保持纯钛锅的真实结构，锅体为细腻均匀的钛金属拉丝，边缘高光克制，手柄连接和铆钉清晰可信。环境为安静现代的厨房台面，背景简洁，使用左上方大面积柔光和轻微轮廓光，接触阴影自然，金属反射不脏不爆。[[图1]] 只参考材质质感与高光控制，不参考其中产品结构和构图。内部 Z 深度只用于空间、遮挡和轮廓，不得把灰度解释为材质、颜色、灯光或背景。输出商业摄影质感，边缘干净，无变形、悬浮、穿插、重复部件或多余文字。
```

图槽职责：`[[图1]]` = 材质与高光。

## Image2 示例

```text
在第一张 C4D 场景母图的原画布上编辑。保持同一摄像机、透视、产品位置、画面占比、遮挡和留白，保持原始宽高关系。只把锅体表面改成真实细腻的纯钛拉丝材质，并补充现代厨房环境和柔和商业摄影灯光。[[图1]] 只参考钛金属表面与高光。不得改变锅体、手柄、锅盖、连接件和灶架结构；不得裁切、扩图、缩放、平移、旋转或新增部件；内部 Z 深度灰度不得作为颜色或光照参考。
```

## 冲突处理

- 用户文字与 C4D 母图的几何、摄像机或构图冲突时，以母图为准，除非用户明确要求改变。
- 普通参考图与母图结构冲突时，只抽取被指定的风格属性。
- 深度图与材质描述无冲突关系：它不提供材质信息。
- 不能从现有信息确定品牌文字、Logo 或结构细节时，要求保持母图，不编造。
