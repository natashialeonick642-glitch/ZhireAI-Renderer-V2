# 挚热 C4D 提示词结构

把用户的视觉目标整理为可直接粘贴到插件提示词框的中文指令。保持用户已经指定的产品、风格、用途、文案和画幅，不自行增加品牌信息或营销卖点。

## 输入角色

- 把插件的“场景”槽视为最高优先级的 C4D 场景母图。它自动作为第一视觉输入，不需要、也不能写成 `[[图1]]`。
- 把插件自动生成的 Z 深度图视为内部几何约束。其约定为近白远黑，无命中区域为黑；只用于空间层次、遮挡、轮廓和镜头关系，不把灰度解释为产品颜色、材质、灯光或背景。
- 把普通参考槽按 `[[图1]]`、`[[图2]]` 顺序引用。只有提示词中出现的槽位会随当前请求发送。每张被引用的图必须有单一、明确的职责。
- 不要求用户在提示词里描述深度图的文件名、路径或技术生成过程。

## 写作流程

1. 从用户输入中提取产品身份、必须保持的结构、目标环境、材质、灯光、色彩、氛围、商业用途和禁止项。缺失但不影响执行的信息不要追问。
2. 默认锁定 C4D 母图的摄像机位置、朝向、透视、焦距、画布、主体包围框、画面占比、遮挡与四周留白。除非用户明确要求重新构图，不得建议裁切、扩图、缩放、平移或旋转产品。
3. 为每张普通参考图分配职责，例如只参考材质、环境、光线、配色、细节或文案排版。不得让普通参考图替代 C4D 产品结构。
4. 按“任务定义 -> 构图锁定 -> 产品结构 -> 材质与色彩 -> 场景与道具 -> 灯光与摄影 -> 参考图职责 -> 质量要求 -> 禁止项”的顺序组织提示词。最终优先输出一段完整、可直接粘贴的中文提示词。
5. 当用户选择“自动”画幅时，写明保持场景母图原始宽高关系，不擅自改成某个近似比例。手动选择画幅时，只复述用户已选的比例。

## 模型适配

- Banana2：明确列出场景母图、每张普通参考图和内部深度约束的优先级；允许较完整的自然语言，但避免重复和相互冲突的镜头描述。
- Image2：使用更短、更直接的编辑指令；先说明“在第一张图原画布上编辑”，再写允许变化的材质、环境和灯光，最后写禁止改变的结构与构图。
- 模型名称不明确时使用 Banana2 的通用结构，但不声称模型一定会像素级遵循深度或构图。

## 输出要求

- 默认只输出“可直接粘贴提示词”。若用户提供了普通参考图，再追加一行简短的“图槽职责”，帮助其检查 `[[图N]]` 对应关系。
- 不输出 API Key、接口地址、文件绝对路径、日志内容或用户素材。
- 不代替用户点击生成，也不调用任何图片或视频生成接口。
- 避免空泛词堆叠。所有风格词都应落到可观察的材质、光线、色彩、背景、景深或后期表现。

需要更详细的结构模板、图槽规则和示例时，读取 [references/prompt-schema.md](references/prompt-schema.md)。
